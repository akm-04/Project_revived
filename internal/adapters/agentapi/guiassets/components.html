GXB operator components

Each section drives one shared component and prints the value it returns as JSON.

ServerPicker

Checkbox list from server.list plus Global (all servers). Returns {global, server_ids}.







PlayerPicker


Online and Search tabs, multi-select. Returns [{player_id, name, server_id}].









ResourcePicker


Catalogue search with icons and quantity. Returns grant lines [{id, amount}].









DurationPicker


1d/3d/7d/15d/30d presets or a custom local start and end. Returns {start, end} as UTC RFC3339.









ConfirmAction


Action summary, required reason and a GUI-generated semantic key under Advanced details. Returns {reason, semantic_key}.
