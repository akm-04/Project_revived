Build gxb-api with postgres,river and gxb-profile-media-maint with postgres on qualified Linux, using portable R2. Keep GXB_PROFILE_MEDIA_ROOT an absolute private owned local directory and GXB_PROFILE_MEDIA_PUBLIC_ORIGIN a trusted literal http origin (no path/query/userinfo/fragment). Both must be supplied when media is enabled or canonical references exist. Empty deployment without references may leave this provider explicitly inactive; stage6/E required-provider activation still applies. Origin is retained in immutable publication history; relocation preserves the externally reachable historical origin, rather than rewriting known outcomes.

For backup, stop all API/publishers, GC and other DB writers for the entire operation. Set GXB_POSTGRES_DSN and root, then run gxb-profile-media-maint -mode backup -bundle /absolute/new/bundle -offline using pinned pg_dump. It takes EX against cooperating publishers, collects typed DB facts, closes DB scopes, exports the custom DB dump and byte-exact blobs plus protection pins and format, then writes a checksum manifest. The offline flag acknowledges an operator procedure, not automatic detection of every writer or a live hot-backup guarantee.

Restore into a new empty database and a nonexistent owned media destination while services remain stopped: set the destination DSN/root and run -mode restore -bundle /absolute/retained/bundle -offline with pinned pg_restore. The command refuses existing DB tables/store, validates bundle hashes, restores, and verifies typed current/history/receipt/pin/byte coherence. Failure leaves incomplete offline recovery state; it does not authorize service restart. Run -mode verify before restarting. API startup also refuses missing/corrupt referenced bytes. Keep pending UNKNOWN pins; receipt absence does not prove abort.

GC uses -mode gc under EX, verifies typed current/history/receipt reachability, resolves only positively committed exact pins, and deletes only unreferenced/unprotected immutable orphans. No age expiry, history pruning, or receipt-miss abort inference is provided. Private operator bundles contain no gameplay bearer secrets from outcomes, but the full DB dump remains private recovery data. Protect its directory accordingly. Anonymous immutable capability URLs cannot revoke cached bytes; qualified profile discovery/block/hide and rich DTO freshness remain stage6 obligations.
